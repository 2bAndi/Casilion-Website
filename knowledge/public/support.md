# How support works

Cassilion support is built for teams that work with an AI agent. Your agent connects to Cassilion's support over MCP and works on the problem together with Cassilion's support AI.

## Connect your AI agent

Create an agent token in the customer area and add the Cassilion MCP server to your agent. The agent can then search this documentation, read known issues, fetch your license file and open tickets for you.

## What happens to a ticket

A ticket is analysed by Cassilion's support AI against the documentation and the product's source code. If it is a usage or configuration question, you get an answer with links into this documentation. If it looks like a defect in Cassilion, the engineering team is told at once and a person replies.

## When a person answers

Reports of data loss, corruption and security problems always go to a person. On plans with human escalation you can ask for a person on any ticket.
